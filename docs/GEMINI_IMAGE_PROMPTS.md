# Gemini Image Generation Prompts - 15 Loại Cây Trồng

## Hướng dẫn sử dụng với Gemini

**Cách generate:**
1. Truy cập Google AI Studio hoặc Gemini API
2. Copy từng prompt dưới đây
3. Generate ảnh với settings:
   - Aspect ratio: 1:1 (square)
   - Quality: Standard hoặc High
   - Safety: Allow creative content
4. Download và đặt tên đúng theo format: `{crop}_seed.png` hoặc `{crop}_ready.png`
5. Resize về 64x64px nếu cần
6. Đặt vào thư mục `public/game-assets/crops/`

**Lưu ý:**
- Gemini tạo ảnh có background - cần xóa background sau bằng tool (remove.bg, Photoshop)
- File output thường >50KB - cần optimize bằng TinyPNG hoặc pngquant
- Generate multiple variants và chọn best output

## Post-Generation Checklist

Sau khi generate xong từ Gemini:

### 1. Remove Background
- [ ] Sử dụng remove.bg hoặc Photoshop Magic Wand
- [ ] Export PNG với transparent background
- [ ] Verify không còn white/colored background artifacts

### 2. Resize & Optimize
- [ ] Resize về đúng 64x64 pixels
- [ ] Maintain aspect ratio khi resize
- [ ] Optimize với TinyPNG hoặc pngquant
- [ ] Target file size <50KB per sprite

### 3. File Naming
- [ ] Đúng format: `{crop}_seed.png` hoặc `{crop}_ready.png`
- [ ] Lowercase với underscore
- [ ] Đặt vào `public/game-assets/crops/`

### 4. Quality Check
- [ ] Transparent background hoàn toàn
- [ ] Readable ở size 64x64px
- [ ] Colors vibrant và consistent
- [ ] Silhouette rõ ràng
- [ ] Progression visible (seed → ready)

### 5. In-Game Test
- [ ] Start dev server
- [ ] Verify sprite renders correctly
- [ ] Check state transitions
- [ ] No broken images
- [ ] Fallback to placeholder nếu thiếu

## Gemini-Specific Tips

**Better results với Gemini:**
- Luôn specify "top-down view" rõ ràng
- Thêm "centered composition" để object ở giữa
- Specify "soft lighting" để tránh harsh shadows
- Dùng "mobile game quality" thay vì "pixel art" (Gemini render smooth hơn)
- Avoid negative prompts - Gemini không support tốt

**Common Gemini issues:**
- Background không transparent → Cần remove sau
- File size lớn → Cần optimize
- Quá detailed → Simplify prompt nếu cần
- Color không vibrant → Thêm "vibrant colors, saturated"

**Nếu output không như ý:**
- Regenerate với seed khác
- Tweak prompt thêm descriptive words
- Generate 3-4 variants và chọn best
