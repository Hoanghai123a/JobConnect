# AI Image Generation Prompts - Nông Trại Game Crops

## Hướng dẫn sử dụng

Các prompts dưới đây được thiết kế cho AI image generation tools (DALL-E, Midjourney, Stable Diffusion).

**Cài đặt chung:**
- Size: 64x64 pixels (hoặc 512x512 rồi resize xuống)
- Format: PNG với transparent background
- Style: Casual 2D farming game, cute, colorful, top-down view
- Optimization: Sau khi tạo, optimize file size xuống <50KB

**Cấu trúc prompt:**
- Base prompt (common settings)
- Specific crop description
- State-specific details

---

```
A game sprite for a casual 2D farming game, 64x64 pixels, top-down view, 
cute and colorful art style, clean silhouette, vibrant colors, 
transparent background, mobile game quality, soft lighting, 
slightly isometric perspective, no excessive detail.
```

## Post-Generation Steps

1. **Generate images** using prompts above
2. **Resize to 64x64px** if generated at higher resolution
3. **Ensure transparent background** - remove any solid backgrounds
4. **Optimize file size** - use tools like TinyPNG, pngquant
5. **Verify naming** - lowercase_underscore format
6. **Place in correct folder** - `public/game-assets/crops/`
7. **Test in game** - verify appearance at actual size

---

## Batch Generation Tips

**For Midjourney:**
- Add `--v 6.1 --ar 1:1 --style raw` for better control
- Use `--no background, shadow, gradient` to avoid unwanted elements

**For DALL-E:**
- Request "PNG with transparent background" explicitly
- Generate at 1024x1024 then resize down
- May need multiple attempts to get transparency right

**For Stable Diffusion:**
- Use model trained on game assets (e.g., "game-icons-sdxl")
- ControlNet with edge detection can ensure consistent style
- Add "transparent background, no background" to negative prompt
