# Milestone 01 — Foundation

Build the project foundation for the farming game.

Tasks:

1. Inspect the existing repo before changing anything.
2. Preserve useful existing conventions.
3. Set up React/Vite/TypeScript if not already present.
4. Add Phaser 3 and Zustand only if missing.
5. Create the source architecture from references/architecture.md.
6. Create domain types/config for crops, player, plots and inventory.
7. Create public/assets directories.
8. Create an initial game-status.md.
9. Add basic Farm route/page and a Phaser mount point.
10. Add a minimal BootScene and FarmScene.
11. Ensure npm scripts work.

Do not implement economy, quests or PocketBase yet.

Acceptance:

- app starts
- /farm renders
- Phaser mounts without errors
- TypeScript/build pass.
