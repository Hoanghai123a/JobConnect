# Art Direction Reference

## Identity

Independent 2D casual farming game.

Do not imitate proprietary characters, logos, UI or exact visual assets from existing games.

## Visual language

- friendly
- colorful
- clean
- soft lighting
- readable silhouettes
- moderate detail
- rounded shapes
- consistent perspective
- consistent shadow direction.

## Camera

Default:

- top-down 2D or slightly isometric.

Do not mix perspectives between assets.

## Suggested starting canvas

- crop sprite: 256×256
- item/icon: 128×128 or 256×256
- character: 512×512
- building: 512×512
- tile: 256×256.

Adjust after the first integrated scene proves the scale.

## Transparency

Characters, crops, buildings, items and effects should normally have transparent backgrounds.

## Asset generation process

1. Lock style guide.
2. Generate a representative character.
3. Generate one crop family.
4. Integrate into Phaser.
5. Validate scale/perspective.
6. Freeze proportions.
7. Generate remaining families.

Do not mass-produce before visual consistency is validated.
